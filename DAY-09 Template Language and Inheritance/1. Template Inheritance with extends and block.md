# 1. Template Inheritance with extends and block

## 1. Introduction

**Template Inheritance** is the most powerful feature of the Django Template Language. It allows you to build a foundational "skeleton" base template containing all the common elements of your site (navigation bar, header, sidebar, footer, CSS/JS links) and define **blocks** that child templates can selectively override.

---

## 2. Why Do We Need It?

Without template inheritance, every HTML file must duplicate 50+ lines of identical `<head>`, meta tags, Bootstrap or Tailwind CDN links, navigation bars, and footer scripts. If you ever need to add a script or change a logo, you would have to edit hundreds of files. Template inheritance enforces the **DRY (Don't Repeat Yourself)** principle across your user interface.

---

## 3. How It Works

1. **Base Template (`base.html`):** Defines the overall document structure using `{% block <name> %}{% endblock %}` placeholders.
2. **Child Template (`home.html`):** Begins with `{% extends 'base.html' %}` as its very first tag and provides content for specific blocks.
3. Django's template engine parses the child, loads the base skeleton, replaces matching block definitions with the child's contents, and keeps base defaults for un-overridden blocks.

---

## 4. Syntax

### Base Template (`templates/base.html`):
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}Django Masterclass{% endblock %}</title>
    {% block extra_css %}{% endblock %}
</head>
<body>
    <header><h1>TechMart Global</h1></header>

    <main>
        {% block content %}
        <!-- Child templates inject page content here -->
        {% endblock %}
    </main>

    <footer>&copy; 2026 TechMart Global. All rights reserved.</footer>
    {% block extra_js %}{% endblock %}
</body>
</html>
```

### Child Template (`templates/store/home.html`):
```html
{% extends 'base.html' %}

{% block title %}Home | TechMart Global{% endblock %}

{% block content %}
    <h2>Featured Products</h2>
    <p>Discover our top-rated technology hardware.</p>
{% endblock %}
```

---

## 5. Practical Examples

### Preserving and Extending Parent Block Content with `{{ block.super }}`
```html
{% extends 'base.html' %}

{% block extra_css %}
    {{ block.super }} <!-- Keeps any CSS linked in base.html! -->
    <link rel="stylesheet" href="/static/css/product_gallery.css">
{% endblock %}
```

---

## 6. Code Explanation

- `{% extends 'base.html' %}`: Tells Django this template inherits from `base.html`. Must be the **first** tag in the file!
- `{% block content %}` ... `{% endblock %}`: Defines an overridable block region.
- `{{ block.super }}`: Injects the content defined inside the parent's block rather than replacing it completely, perfect for appending page-specific CSS or JS bundles.

---

## 7. Expected Output

When `home.html` is rendered, the browser receives the full merged HTML:
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Home | TechMart Global</title>
</head>
<body>
    <header><h1>TechMart Global</h1></header>
    <main>
        <h2>Featured Products</h2>
        <p>Discover our top-rated technology hardware.</p>
    </main>
    <footer>&copy; 2026 TechMart Global. All rights reserved.</footer>
</body>
</html>
```

---

## 8. Real-World Use Case

Enterprise applications typically implement a three-tier inheritance hierarchy:
1. `base.html`: Universal HTML headers, fonts, global analytics scripts.
2. `base_dashboard.html`: Inherits `base.html` and adds sidebar layout, profile header.
3. `user_settings.html`: Inherits `base_dashboard.html` and provides specific form inputs.

---

## 9. Common Mistakes

1. **Putting markup above `{% extends %}`:**
   ```html
   <!-- INCORRECT: -->
   <div>Welcome</div> <!-- TemplateSyntaxError! Must be inside a block -->
   {% extends 'base.html' %}
   ```
2. **Duplicate block names in the same template:** Each block within a template must have a unique identifier.

---

## 10. Best Practices

- Keep `{% extends %}` as the absolute first tag in child templates.
- Define granular blocks: `{% block title %}`, `{% block content %}`, `{% block extra_css %}`, `{% block extra_js %}`.
- Use `{{ block.super }}` when you want to extend rather than overwrite parent assets.

## 12. Interview Questions

**Q1: How does template inheritance in Django improve application maintainability?**  
*Answer:* It eliminates duplicated boilerplate across HTML files. Common UI elements (navigation, footers, stylesheets, scripts) are centralized in a single base file. Changes made in the base template instantly cascade across all child pages without editing individual templates.

**Q2: What happens if a child template does not override a block defined in the parent?**  
*Answer:* If a child template omits a block, Django automatically renders whatever fallback or default content was defined between the `{% block %}` and `{% endblock %}` tags in the parent template.

---

## 13. Summary

- `{% extends %}` inherits from a parent skeleton.
- `{% block %}` defines placeholder regions to override.
- `{{ block.super }}` retains and extends parent content.
