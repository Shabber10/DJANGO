# 3. URL and Static Template Tags

## 1. Introduction

Templates must link to other pages and assets (CSS, JavaScript, images). Rather than hardcoding paths, Django provides two essential built-in template tags: **`{% url %}`** for reverse URL resolution and **`{% static %}`** for resolving static asset URLs.

---

## 2. Why Do We Need It?

- Hardcoding `<a href="/articles/10/">` breaks if URL routing paths change.
- Hardcoding `<img src="/static/img/logo.png">` breaks in production environments where assets are hosted on CDNs (CloudFront, Cloudinary, AWS S3) or cache-busted with unique hash suffixes (WhiteNoise).
- `{% url %}` and `{% static %}` dynamically compute the exact, current public paths.

---

## 3. How It Works

- **`{% url 'namespace:name' arg1=val1 %}`:** Evaluates at template render time by querying Django's URL resolver, returning the exact relative URL string.
- **`{% static 'path/to/asset' %}`:** Requires `{% load static %}` at the top of the file. It queries the configured `STATICFILES_STORAGE` backend in `settings.py` to produce the full public asset URL.

---

## 4. Syntax

```html
{% load static %}

<!-- Dynamic URL generation -->
<a href="{% url 'blog:post_detail' pk=post.id %}">Read Post</a>
<a href="{% url 'accounts:login' %}">Sign In</a>

<!-- Dynamic Static Asset Resolution -->
<link rel="stylesheet" href="{% static 'css/style.css' %}">
<img src="{% static 'images/logo.png' %}" alt="Company Logo">
<script src="{% static 'js/app.js' %}"></script>
```

---

## 5. Practical Examples

### Complete Navigation and Asset Integration
```html
{% load static %}
<!DOCTYPE html>
<html>
<head>
    <title>Masterclass Portal</title>
    <link rel="stylesheet" href="{% static 'vendor/bootstrap/bootstrap.min.css' %}">
    <link rel="stylesheet" href="{% static 'css/main.css' %}">
</head>
<body>
    <nav class="navbar">
        <a class="navbar-brand" href="{% url 'home' %}">
            <img src="{% static 'images/brand_logo.svg' %}" width="30" height="30" alt="Logo">
            Masterclass
        </a>
        <div class="nav-links">
            <a href="{% url 'courses:list' %}">Courses</a>
            <a href="{% url 'blog:index' %}">Blog</a>
            {% if user.is_authenticated %}
                <a href="{% url 'accounts:dashboard' %}">Dashboard ({{ user.username }})</a>
                <a href="{% url 'accounts:logout' %}">Logout</a>
            {% else %}
                <a href="{% url 'accounts:login' %}">Login</a>
                <a href="{% url 'accounts:register' %}">Register</a>
            {% endif %}
        </div>
    </nav>
    <script src="{% static 'js/main.js' %}"></script>
</body>
</html>
```

---

## 6. Code Explanation

- `{% load static %}`: Instructs Django to load the static tag library into the current template scope.
- `{% url 'courses:list' %}`: Resolves the URL pattern with `name='list'` inside the `courses` namespace.
- `{% static 'images/brand_logo.svg' %}`: Converts the asset path into `/static/images/brand_logo.svg` (or an S3 bucket URL in production).

---

## 8. Real-World Use Case

When deploying Django to production with AWS S3, changing `STATIC_URL` to `https://mybucket.s3.amazonaws.com/static/` instantly updates every single image, CSS, and JS tag across the entire site without modifying any templates.

---

## 9. Common Mistakes

1. **Forgetting `{% load static %}`:** Causes `TemplateSyntaxError: Invalid block tag on line 3: 'static'`.
2. **Missing quotes around URL names:**
   ```html
   <!-- INCORRECT: -->
   <a href="{% url home %}">Home</a> <!-- Treats home as a variable! -->
   <!-- CORRECT: -->
   <a href="{% url 'home' %}">Home</a>
   ```

---

## 10. Best Practices

- Always use `{% url %}` for navigation links and form action targets.
- Always load static tags at the top of templates referencing media or stylesheets (`{% load static %}`).
- Store URL lookup targets in template variables if needed frequently:
  `{% url 'blog:detail' pk=item.id as detail_url %}`.

## 12. Interview Questions

**Q1: What is the difference between `{% url %}` and hardcoding a path in an anchor tag?**  
*Answer:* Hardcoded paths are brittle and break when URL routes or prefixes are modified in `urls.py`. `{% url %}` performs reverse URL resolution dynamically based on route names, ensuring all links stay updated automatically when route configurations change.

**Q2: How does `{% static %}` interact with production storage backends?**  
*Answer:* `{% static %}` delegates resolution to the configured storage backend (`STATICFILES_STORAGE`). In production with backends like `ManifestStaticFilesStorage` or `S3Boto3Storage`, it automatically appends MD5 cache-busting hashes (e.g., `style.b234fae23.css`) or full CDN/S3 bucket URLs to the asset path.

---

## 13. Summary

- `{% url %}` generates dynamic internal page links.
- `{% static %}` resolves CSS, JS, and image asset URLs.
- Always include `{% load static %}` when referencing static assets.
