# 4. VS Code Setup and Common Installation Errors

## 1. Introduction

Configuring your code editor properly transforms your developer experience. Visual Studio Code (VS Code) is the most widely adopted editor for Python and Django. Configuring the Python extension, linter, and Django template syntax highlighting prevents frustrating bugs and accelerates development.

---

## 2. Why Do We Need It?

Without proper IDE setup:
- VS Code may use the global Python interpreter and flag installed packages like `django` as `Import 'django' could not be resolved`.
- Django template tags like `{% for %}` will appear as unhighlighted raw text.
- Terminal sessions won't auto-activate the virtual environment.

---

## 3. How It Works

VS Code stores workspace settings in a hidden `.vscode/settings.json` file. By setting `python.defaultInterpreterPath` to your `venv`, VS Code connects its language server (Pylance) directly to the packages installed inside your environment.

---

## 4. Syntax

Recommended `.vscode/settings.json`:

```json
{
    "python.defaultInterpreterPath": "${workspaceFolder}/venv/Scripts/python.exe",
    "python.analysis.typeCheckingMode": "basic",
    "files.associations": {
        "**/templates/**/*.html": "django-html"
    },
    "[django-html]": {
        "editor.tabSize": 2
    }
}
```
*(On macOS/Linux, replace `venv/Scripts/python.exe` with `venv/bin/python`).*

---

## 5. Practical Examples

### Selecting the Interpreter via GUI
1. Open your project folder in VS Code (`File > Open Folder...`).
2. Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on Mac) to open the Command Palette.
3. Type: `Python: Select Interpreter`.
4. Choose the interpreter marked with `('venv': venv)`.

---

## 6. Code Explanation

- `files.associations`: Maps all HTML files inside `templates/` folders to the `django-html` language mode, enabling syntax highlighting and auto-closing tags for DTL.
- `python.defaultInterpreterPath`: Pins the interpreter so any new terminal session opened via `Ctrl + ~` automatically runs `activate`.

---

## 7. Expected Output

When configured correctly:
- The bottom right status bar in VS Code displays: `Python 3.11.x ('venv': venv)`.
- Opening a new integrated terminal displays: `(venv) PS C:\...`.
- In `views.py`, typing `from django.` offers instant autocompletions for `http`, `shortcuts`, `urls`, and `db`.

---

## 8. Real-World Use Case

Development teams check in `.vscode/extensions.json` and `.vscode/settings.json` so every team member shares identical formatting rules, linting standards, and interpreter defaults across machines.

---

## 9. Common Mistakes

### Common Errors & Solutions:
1. **Error:** `Import "django" could not be resolved (reportMissingImports)`  
   *Cause:* VS Code is pointing to the global Python instead of `venv`.  
   *Solution:* Use `Python: Select Interpreter` and pick `./venv/Scripts/python.exe`.
2. **Error:** `ModuleNotFoundError: No module named 'django'` when running in terminal.  
   *Cause:* Virtual environment is not activated in that terminal tab.  
   *Solution:* Run activation script or restart terminal.

---

## 10. Best Practices

- Install the **Python** extension by Microsoft.
- Install the **Django** extension by Baptiste Darthenay for template syntax support.
- Keep `.vscode/settings.json` configured for project portability.

## 12. Interview Questions

**Q1: How do you configure debugging for a Django application in VS Code?**  
*Answer:* Create `.vscode/launch.json` with a configuration of type `debugpy`, request `launch`, program `${workspaceFolder}/manage.py`, and args `["runserver", "--noreload", "--nothreading"]`. The `--noreload` flag ensures breakpoints bind reliably to the primary process.

**Q2: What is Pylance in VS Code and how does it assist Django development?**  
*Answer:* Pylance is the Python language server in VS Code powered by Pyright. It provides static type checking, docstring popups, automatic import suggestions, and code navigation (Go to Definition) across your codebase and installed libraries.

---

## 13. Summary

- VS Code requires selecting the interpreter located inside `venv/`.
- Django template highlighting is enabled via file associations.
- Debugging and linting settings can be versioned in `.vscode/settings.json`.
