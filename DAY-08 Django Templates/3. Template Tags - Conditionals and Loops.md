# 3. Template Tags - Conditionals and Loops

## 1. Introduction

Control flow in templates is achieved through **Template Tags**. The two most critical control flow tags are conditional branching with **`{% if %}`** and collection iteration with **`{% for %}`**.

---

## 2. Why Do We Need It?

Web interfaces must adapt dynamically to state:
- Displaying login buttons for guests vs logout buttons for authenticated users.
- Generating tables of database records dynamically.
- Handling empty states gracefully when a search query returns zero results.

---

## 3. How It Works

- `{% if %}` evaluates boolean expressions, supporting operators: `and`, `or`, `not`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `in`, and `is`.
- `{% for %}` iterates over any iterable (list, tuple, QuerySet). Inside the loop, Django provides a special **`forloop`** variable containing loop metadata (e.g., `forloop.counter`, `forloop.first`, `forloop.last`).
- The `{% empty %}` clause specifies fallback markup if the list is empty or nonexistent.

---

## 4. Syntax

### Conditionals Syntax:
```html
{% if score >= 90 %}
    <span class="badge green">Grade: A</span>
{% elif score >= 75 %}
    <span class="badge blue">Grade: B</span>
{% else %}
    <span class="badge red">Grade: Needs Improvement</span>
{% endif %}
```

### Loops Syntax with Empty Block:
```html
<ul>
{% for item in product_list %}
    <li>{{ forloop.counter }}. {{ item.name }} - ${{ item.price }}</li>
{% empty %}
    <li>No products found matching your search.</li>
{% endfor %}
</ul>
```

---

## 5. Practical Examples

### Exploring the `forloop` Object
```html
<table>
    <thead>
        <tr><th>#</th><th>Product</th><th>Status</th></tr>
    </thead>
    <tbody>
    {% for product in products %}
        <tr class="{% if forloop.first %}first-row{% elif forloop.last %}last-row{% endif %}">
            <td>{{ forloop.counter }}</td> <!-- 1-indexed count -->
            <td>{{ product.name }}</td>
            <td>
                {% if product.in_stock and product.quantity > 0 %}
                    <span style="color: green;">In Stock ({{ product.quantity }})</span>
                {% else %}
                    <span style="color: red;">Out of Stock</span>
                {% endif %}
            </td>
        </tr>
    {% empty %}
        <tr><td colspan="3">Your inventory is currently empty.</td></tr>
    {% endfor %}
    </tbody>
</table>
```

---

## 6. Code Explanation

- `forloop.counter`: The current 1-indexed iteration counter (1, 2, 3...).
- `forloop.counter0`: The 0-indexed iteration counter (0, 1, 2...).
- `forloop.revcounter`: Number of iterations from the end (counting down to 1).
- `forloop.first` / `forloop.last`: Booleans returning `True` on the first or last iteration.
- `{% empty %}`: Replaces awkward `{% if products %}{% for %}{% else %}` nesting with a clean, idiomatic pattern.

---

## 7. Expected Output

Rendered HTML table:
```html
<table>
    <thead><tr><th>#</th><th>Product</th><th>Status</th></tr></thead>
    <tbody>
        <tr class="first-row">
            <td>1</td>
            <td>Wireless Mouse</td>
            <td><span style="color: green;">In Stock (45)</span></td>
        </tr>
        <tr class="last-row">
            <td>2</td>
            <td>Mechanical Keyboard</td>
            <td><span style="color: red;">Out of Stock</span></td>
        </tr>
    </tbody>
</table>
```

---

## 8. Real-World Use Case

Rendering data tables with alternating row stripes, numbering paginated search results, displaying permission-based navigation links, and handling zero-data states in dashboards.

---

## 9. Common Mistakes

1. **Forgetting closing tags:** Every `{% if %}` requires an `{% endif %}`, and every `{% for %}` requires an `{% endfor %}`.
2. Attempting to use Python assignments inside tags (e.g., `{% x = 5 %}` is invalid; DTL does not support arbitrary variable assignments).

---

## 10. Best Practices

- Always use `{% empty %}` instead of wrapping loops with outer `{% if %}` tags.
- Keep conditionals simple; if an expression requires 4 `and`/`or` chains, compute a boolean property on your model or view instead.

---

1. **[Basic]** What closing tag is required for `{% for %}`?
2. **[Basic]** What is the difference between `forloop.counter` and `forloop.counter0`?
3. **[Intermediate]** How does the `{% empty %}` tag simplify handling empty lists in DTL?
4. **[Intermediate]** How can you check if the current iteration is the last element in a loop?
5. **[Advanced]** How do you iterate over key-value pairs of a Python dictionary inside a Django template?

---

## 12. Interview Questions

**Q1: How do you iterate over a dictionary's keys and values in a Django template?**  
*Answer:* By calling `.items` on the dictionary variable in the for loop:
```html
{% for key, value in my_dict.items %}
    <p>{{ key }}: {{ value }}</p>
{% endfor %}
```

**Q2: What is `forloop.parentloop`?**  
*Answer:* In nested for loops, `forloop.parentloop` provides access to the `forloop` context of the outer enclosing loop (e.g. `{{ forloop.parentloop.counter }}`).

---

## 13. Summary

- `{% if %}` provides conditional logic with standard boolean operators.
- `{% for %}` iterates over collections and provides the `forloop` metadata object.
- `{% empty %}` handles empty collection states cleanly.
