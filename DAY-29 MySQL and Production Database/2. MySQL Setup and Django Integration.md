# 2. MySQL Setup and Django Integration

## 1. Introduction

Connecting Django to a MySQL database requires installing a Python MySQL database connector, provisioning a dedicated MySQL database and user with appropriate privileges, and configuring Django's `DATABASES` dictionary. The recommended, officially supported connector is `mysqlclient`.

---

## 2. Why Do We Need It?

Python cannot communicate with MySQL servers directly without an adapter implementing the Python Database API Specification (PEP 249). `mysqlclient` is a C-based wrapper around `libmysqlclient` providing top performance, security, and native Django ORM compatibility.

---

## 3. How It Works

1. Install MySQL Server (locally or via Docker/cloud).
2. Create dedicated database: `CREATE DATABASE ems_db CHARACTER SET utf8mb4;`.
3. Create dedicated application user and grant permissions: `GRANT ALL PRIVILEGES ON ems_db.* TO 'ems_user'@'localhost';`.
4. Install `mysqlclient` in virtual environment: `pip install mysqlclient`.
5. Update `settings.py` `DATABASES` configuration.
6. Execute `python manage.py migrate`.

---

## 4. Syntax

```sql
-- MySQL Shell Commands
CREATE DATABASE ems_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER 'ems_user'@'localhost' IDENTIFIED BY 'StrongP@ssw0rd2026';

GRANT ALL PRIVILEGES ON ems_db.* TO 'ems_user'@'localhost';

FLUSH PRIVILEGES;
```

## 5. Practical Examples

### Complete Django `settings.py` Configuration for MySQL
```python
# File: settings.py
import os
from pathlib import Path
from dotenv import load_dotenv

load_dotenv()

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': os.getenv('DB_NAME', 'ems_db'),
        'USER': os.getenv('DB_USER', 'ems_user'),
        'PASSWORD': os.getenv('DB_PASSWORD', 'StrongP@ssw0rd2026'),
        'HOST': os.getenv('DB_HOST', '127.0.0.1'),
        'PORT': os.getenv('DB_PORT', '3306'),
        'OPTIONS': {
            'charset': 'utf8mb4',
            'init_command': "SET sql_mode='STRICT_TRANS_TABLES'",
        },
        'CONN_MAX_AGE': 600,  # Enable connection pooling for 10 minutes
    }
}
```

---

## 6. Code Explanation

- `pip install mysqlclient`: C-extension providing native bindings. On Windows, precompiled wheels are installed automatically by pip.
- `CONN_MAX_AGE`: Reuses database connections across multiple HTTP requests for up to 600 seconds, reducing TCP handshake overhead.
- `dotenv`: Loads configuration values from a secure `.env` file that is excluded from Git.

## 8. Real-World Use Case

**Production Deployment on AWS RDS MySQL:**
When deploying to AWS Elastic Beanstalk or EC2, Django connects to an Amazon RDS MySQL Multi-AZ database instance, ensuring high availability, automatic failover, and automated nightly snapshots.

---

## 9. Common Mistakes

1. **Windows Build Tools Missing:** Installing `mysqlclient` from source on Windows without Visual C++ Build Tools. Fix: ensure `pip install wheel` is up-to-date to fetch pre-built wheels, or use `PyMySQL` with `pymysql.install_as_MySQLdb()`.
2. **Access Denied Error:** Forgetting to run `FLUSH PRIVILEGES;` after granting user permissions in MySQL.
3. **Connection Timeouts:** Leaving `CONN_MAX_AGE = None` causes Django to open and close a new MySQL connection on every single HTTP request.

---

## 10. Best Practices

- Always configure `CONN_MAX_AGE` (typically 300 to 600 seconds) to avoid database connection churn.
- Never use the MySQL `root` user for the application; create a dedicated user with access limited only to the application database.
- Use `127.0.0.1` instead of `localhost` on Linux to avoid Unix socket lookup issues.

## 12. Interview Questions

**Q1: What is the difference between `mysqlclient` and `PyMySQL`?**
*Answer:* `mysqlclient` is a C-extension wrapping the official MySQL C client library (`libmysqlclient`). It is significantly faster and is Django's officially recommended driver. `PyMySQL` is written entirely in pure Python; while slower, it has no C compilation dependencies and can run on environments where compiling native extensions is restricted.

**Q2: How does Django's `CONN_MAX_AGE` setting improve performance?**
*Answer:* By default (`CONN_MAX_AGE = 0`), Django opens a new database connection at the beginning of each request and closes it at the end. Establishing a TCP connection and performing SSL handshakes and authentication incurs latency (typically 10-50ms). Setting `CONN_MAX_AGE` to a positive integer keeps connections open and reuses them across requests, dramatically improving throughput.

---

## 13. Summary

- `mysqlclient` is the officially supported high-performance MySQL driver for Django.
- Always create dedicated databases with `utf8mb4` charset and dedicated least-privilege users.
- Use `CONN_MAX_AGE` for persistent database connection pooling.
- Manage database secrets via `.env`.
