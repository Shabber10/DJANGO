# 3. Static, Media, and Internationalization Settings

## 1. Introduction

Web applications need stylesheets, JavaScript files, images, and localized date/time representations. Django categorizes these assets into **Static Files** (developer-authored assets like CSS/JS) and **Media Files** (user-uploaded files like profile pictures), governed by dedicated settings in `settings.py`.

---

## 2. Why Do We Need It?

- Developer assets (CSS, JS, logos) must be served efficiently and cached aggressively.
- User uploads must be stored in secure, distinct directories to prevent unauthorized code execution.
- Global applications need accurate timezones and localized date formatting.

---

## 3. How It Works

### Configuration Settings:
- **`STATIC_URL`:** The URL prefix used in HTML templates to refer to static files (e.g., `'/static/'`).
- **`STATICFILES_DIRS`:** List of additional filesystem directories where Django searches for static assets during development.
- **`STATIC_ROOT`:** Absolute directory where `collectstatic` compiles all static files for production deployment.
- **`MEDIA_URL`:** The URL prefix for user-uploaded media (e.g., `'/media/'`).
- **`MEDIA_ROOT`:** Absolute filesystem directory where uploaded files are saved.
- **`TIME_ZONE`:** Timezone string (e.g. `'UTC'`, `'Asia/Kolkata'`, `'America/New_York'`).

---

## 4. Syntax

```python
# Static files configuration
STATIC_URL = '/static/'
STATICFILES_DIRS = [BASE_DIR / 'static']
STATIC_ROOT = BASE_DIR / 'staticfiles'

# Media files configuration
MEDIA_URL = '/media/'
MEDIA_ROOT = BASE_DIR / 'media'

# Localization & Timezone
LANGUAGE_CODE = 'en-us'
TIME_ZONE = 'UTC'
USE_I18N = True
USE_TZ = True
```

---

## 5. Practical Examples

### Setting up Indian Standard Time (IST) or US Eastern Time
```python
# For IST:
TIME_ZONE = 'Asia/Kolkata'

# For US Eastern:
# TIME_ZONE = 'America/New_York'

USE_TZ = True  # Stores datetimes in UTC in database, renders in local timezone
```

---

## 6. Code Explanation

- `USE_TZ = True`: Django stores timestamps in the database in UTC, but automatically converts them to `TIME_ZONE` when rendering in templates or forms.
- `BASE_DIR / 'static'`: Uses Python 3's `pathlib` operator `/` to join filesystem paths cleanly.

---

## 7. Expected Output

When displaying `{{ article.created_at }}` in templates with `TIME_ZONE = 'Asia/Kolkata'`:
The time automatically converts from UTC database storage to localized IST output.

---

## 8. Real-World Use Case

In multi-tenant SaaS applications, setting `USE_TZ = True` allows each user to view timestamps formatted in their personal local timezone while preserving UTC consistency in the database.

---

## 9. Common Mistakes

1. Confusing `STATICFILES_DIRS` with `STATIC_ROOT`. During development, Django reads from `STATICFILES_DIRS`. In production, web servers serve files gathered in `STATIC_ROOT`.
2. Setting `STATIC_ROOT = BASE_DIR / 'static'` when `STATICFILES_DIRS = [BASE_DIR / 'static']`. They must NEVER point to the same folder!

---

## 10. Best Practices

- Always keep `USE_TZ = True`.
- Never store uploaded user media inside the `static/` folder.
- Ensure `media/` is listed in `.gitignore`.

## 12. Interview Questions

**Q1: What is the purpose of `collectstatic` and `STATIC_ROOT`?**  
*Answer:* In production, running Python to serve individual CSS/JS files is slow and inefficient. `python manage.py collectstatic` crawls all apps and `STATICFILES_DIRS`, copying every static asset into the single directory defined by `STATIC_ROOT`, allowing Nginx, Apache, or WhiteNoise to serve them directly with high caching performance.

**Q2: Why should `MEDIA_ROOT` never be placed inside the source code repository?**  
*Answer:* User-uploaded media grows indefinitely, bloats the Git repository history, and can present security vulnerabilities if executable scripts uploaded by users are stored alongside application source code.

---

## 13. Summary

- Static files are developer assets (CSS/JS); Media files are user uploads.
- `STATIC_URL` and `MEDIA_URL` govern public URL paths.
- `USE_TZ = True` ensures UTC database storage with localized display.
