## Part 2: System Architecture & Data Modeling Scenario (25 Points)

#### Scenario: Enterprise Hospital Patient Management System
**Requirements:**
1. Custom User model supporting three roles: `PATIENT`, `DOCTOR`, `ADMIN`.
2. `Appointment` entity linking `Patient` and `Doctor`.
3. An appointment must have a `date`, `time_slot`, `status` (`PENDING`, `CONFIRMED`, `COMPLETED`, `CANCELLED`), and `fee`.
4. **Database Constraint:** A doctor cannot have two appointments at the exact same `date` and `time_slot`.
5. **Database Constraint:** Appointment `fee` must strictly be greater than zero.
6. Provide an abstract base model for audit timestamps (`created_at`, `updated_at`).

**Model Implementation:**
```python
# File: apps/appointments/models.py
from django.db import models
from django.conf import settings
from django.db.models import Q

class TimeStampedModel(models.Model):
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        abstract = True

class Appointment(TimeStampedModel):
    STATUS_CHOICES = [
        ('PENDING', 'Pending Confirmation'),
        ('CONFIRMED', 'Confirmed'),
        ('COMPLETED', 'Completed'),
        ('CANCELLED', 'Cancelled'),
    ]
    patient = models.ForeignKey(
        settings.AUTH_USER_MODEL,
        on_delete=models.CASCADE,
        related_name='patient_appointments'
    )
    doctor = models.ForeignKey(
        settings.AUTH_USER_MODEL,
        on_delete=models.CASCADE,
        related_name='doctor_appointments'
    )
    date = models.DateField()
    time_slot = models.TimeField()
    status = models.CharField(max_length=15, choices=STATUS_CHOICES, default='PENDING')
    fee = models.DecimalField(max_digits=8, decimal_places=2)

    class Meta:
        # Constraint 1: Prevent double booking of doctors
        constraints = [
            models.UniqueConstraint(
                fields=['doctor', 'date', 'time_slot'],
                name='unique_doctor_schedule_slot'
            ),
            # Constraint 2: Positive fee
            models.CheckConstraint(
                check=Q(fee__gt=0),
                name='chk_appointment_fee_positive'
            ),
        ]
        indexes = [
            models.Index(fields=['doctor', 'date'], name='idx_appt_doc_date'),
            models.Index(fields=['status'], name='idx_appt_status'),
        ]

    def __str__(self):
        return f"Dr. {self.doctor.last_name} with {self.patient.get_full_name()} on {self.date}"
```

## Part 3: Full-Stack Implementation (30 Points)

#### Problem: Doctor Appointment REST API with JWT Authentication
**Requirements:**
1. DRF `ModelSerializer` for `Appointment`.
2. DRF `ModelViewSet` with:
   - Authenticated patients can view only their own appointments.
   - Doctors can view appointments assigned to them.
   - Administrators can view all appointments.
   - Creating an appointment automatically assigns `request.user` as `patient`.
3. SimpleJWT authentication integration.

**Implementation:**
```python
# File: apps/appointments/serializers.py
from rest_framework import serializers
from .models import Appointment

class AppointmentSerializer(serializers.ModelSerializer):
    patient_name = serializers.CharField(source='patient.get_full_name', read_only=True)
    doctor_name = serializers.CharField(source='doctor.get_full_name', read_only=True)

    class Meta:
        model = Appointment
        fields = [
            'id', 'patient', 'patient_name', 'doctor', 'doctor_name',
            'date', 'time_slot', 'status', 'fee', 'created_at'
        ]
        read_only_fields = ['patient', 'status']

# File: apps/appointments/views.py
from rest_framework import viewsets, permissions
from .models import Appointment
from .serializers import AppointmentSerializer

class AppointmentViewSet(viewsets.ModelViewSet):
    serializer_class = AppointmentSerializer
    permission_classes = [permissions.IsAuthenticated]

    def get_queryset(self):
        user = self.request.user
        if user.is_superuser or user.role == 'ADMIN':
            return Appointment.objects.select_related('patient', 'doctor').all()
        elif user.role == 'DOCTOR':
            return Appointment.objects.select_related('patient', 'doctor').filter(doctor=user)
        # Default: Patient
        return Appointment.objects.select_related('patient', 'doctor').filter(patient=user)

    def perform_create(self, serializer):
        # Automatically assign logged in patient
        serializer.save(patient=self.request.user)
```

## Part 4: Advanced Production Debugging Challenge (25 Points)

#### Challenge 1: Resolving Severe N+1 Query Cascade in Patient History API
**Buggy Implementation:**
```python
# API View that triggers 300+ database queries for 100 appointments:
class AppointmentHistoryView(ListAPIView):
    serializer_class = AppointmentSerializer
    queryset = Appointment.objects.all()
```
**Diagnosis:** The serializer accesses `patient.get_full_name` and `doctor.get_full_name`. Django executes 1 query for appointments, 100 queries for patients, and 100 queries for doctors (201 total queries).  
**Solution:**
```python
class AppointmentHistoryView(ListAPIView):
    serializer_class = AppointmentSerializer
    queryset = Appointment.objects.select_related('patient', 'doctor').all()
    # Reduces query count from 201 to exactly 1 query!
```

#### Challenge 2: Lost Update Race Condition During Seat Reservation
**Buggy Implementation:**
```python
def reserve_slot(slot_id):
    slot = Slot.objects.get(id=slot_id)
    if slot.available_seats > 0:
        slot.available_seats -= 1
        slot.save()
        return True
    return False
```
**Diagnosis:** Under concurrent traffic, two requests read `available_seats = 1` simultaneously. Both decrement to 0. Both succeed, resulting in an oversold slot.  
**Solution:**
```python
from django.db import transaction

def reserve_slot(slot_id):
    with transaction.atomic():
        # Acquire row lock:
        slot = Slot.objects.select_for_update().get(id=slot_id)
        if slot.available_seats > 0:
            slot.available_seats -= 1
            slot.save()
            return True
        return False
```
