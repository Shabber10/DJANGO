## Section A: Multiple-Choice Questions

#### Q1. What is the role of Nginx when placed in front of Gunicorn in a production architecture?
- [ ] **A**. It runs Django migrations automatically.
- [ ] **B**. It acts as a reverse proxy: terminates SSL/TLS, buffers slow clients, serves cached static files, and routes dynamic traffic to Gunicorn.
- [ ] **C**. It replaces the MySQL database engine.
- [ ] **D**. It compiles Python code into bytecode.

**Answer:** B. It acts as a reverse proxy: terminates SSL/TLS, buffers slow clients, serves cached static files, and routes dynamic traffic to Gunicorn.  
*Explanation:* Gunicorn is an application server, not a battle-tested public-facing web server. Nginx defends against Slowloris attacks, offloads TLS decryption, and handles static assets at native C speed.

#### Q2. How does WhiteNoise enable cache-busting in production?
- [ ] **A**. By clearing browser cookies on every reload.
- [ ] **B**. By computing an MD5 hash of each static file's content and appending it to the filename (e.g. `main.a9f1b2c3.css`), allowing forever-cache HTTP headers.
- [ ] **C**. By querying Redis on every image request.
- [ ] **D**. By disabling HTTP caching.

**Answer:** B. By computing an MD5 hash of each static file's content and appending it to the filename, allowing forever-cache HTTP headers.  
*Explanation:* `CompressedManifestStaticFilesStorage` generates unique content hashes. Browsers can cache assets for 1 year; if the file changes, the hash changes, busting the cache automatically.

#### Q3. In a production Dockerfile, why should containers never run as the `root` user?
- [ ] **A**. Docker refuses to build images running as root.
- [ ] **B**. If an attacker achieves Remote Code Execution (RCE) and breaks out of container isolation, they would have root privileges on the host server.
- [ ] **C**. Root users cannot execute Python scripts.
- [ ] **D**. Python runs 50% slower as root.

**Answer:** B. If an attacker achieves Remote Code Execution (RCE) and breaks out of container isolation, they would have root privileges on the host server.  
*Explanation:* Running as an unprivileged user (`USER appuser`) enforces the principle of least privilege and limits the blast radius of any container escape exploit.

#### Q4. What happens if user-uploaded media files are stored on the local container filesystem on cloud PaaS platforms like Render or Heroku?
- [ ] **A**. Uploads are saved permanently to the database.
- [ ] **B**. Uploaded files will be permanently lost whenever the container sleeps, restarts, or deploys a new release due to ephemeral filesystems.
- [ ] **C**. The platform duplicates files across 3 regions.
- [ ] **D**. Uploads are converted to base64 strings.

**Answer:** B. Uploaded files will be permanently lost whenever the container sleeps, restarts, or deploys a new release due to ephemeral filesystems.  
*Explanation:* Cloud containers have ephemeral disk storage. Decoupled object storage (e.g., AWS S3, Cloudflare R2, Google Cloud Storage) is mandatory for media files.

#### Q5. What free tool automates obtaining and renewing Let's Encrypt TLS/SSL certificates on Ubuntu Linux servers?
- [ ] **A**. OpenSSL
- [ ] **B**. Certbot
- [ ] **C**. Nginx-SSL
- [ ] **D**. Cloudflare CLI

**Answer:** B. Certbot  
*Explanation:* `certbot --nginx` automatically verifies domain ownership, provisions TLS certificates, configures Nginx HTTPS redirects, and schedules automatic renewal via systemd timers.

## Section B: Conceptual and Scenario-Based Questions

#### Scenario 1: Multi-Container Docker Architecture
**Question:** Design a complete multi-container production architecture for the Employee Management System using Docker Compose, orchestrating web, database, cache, and asynchronous workers.

**Model Answer:**
The multi-container stack consists of 4 isolated services on a shared internal bridge network:
1. `db`: `mysql:8.0` container with named volume `mysql_data` mounted to `/var/lib/mysql` for persistence.
2. `redis`: `redis:7-alpine` container acting as the message broker for Celery and in-memory cache.
3. `web`: Built from the project `Dockerfile`, running Gunicorn (`gunicorn myproject.wsgi:application --bind 0.0.0.0:8000`), dependent on `db` and `redis`.
4. `celery_worker`: Built from the same application image, executing `celery -A ems_project worker --loglevel=info`, consuming tasks from Redis.

## Section C: Practical Coding Exercises

#### Exercise 1: Production Multi-Stage Dockerfile
**Problem Statement:** Write a production-ready, secure multi-stage `Dockerfile` that:
1. Uses `python:3.12-slim-bookworm`.
2. Sets `PYTHONDONTWRITEBYTECODE=1` and `PYTHONUNBUFFERED=1`.
3. Installs MySQL development headers and Python dependencies.
4. Collects static assets.
5. Creates and switches to an unprivileged user `appuser`.
6. Launches Gunicorn on port 8000 with 3 workers.

```dockerfile
# Write your solution code here
```

**Correct Code Solution:**
```dockerfile
FROM python:3.12-slim-bookworm

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc \
    default-libmysqlclient-dev \
    pkg-config \
    curl \
    && rm -rf /var/lib/apt/lists/*

# Install Python packages
COPY requirements.txt /app/
RUN pip install --no-cache-dir -r requirements.txt

# Copy application source code
COPY . /app/

# Collect static assets
RUN python manage.py collectstatic --noinput

# Security: Create non-root user and transfer ownership
RUN useradd -m -u 1000 appuser && chown -R appuser:appuser /app
USER appuser

EXPOSE 8000

CMD ["gunicorn", "ems_project.wsgi:application", "--bind", "0.0.0.0:8000", "--workers", "3"]
```

## Section D: Debugging Tasks

#### Task 1: Infinite HTTPS Redirection Loop Behind Reverse Proxy
**Buggy Code Snippet:**
```python
# settings.py
SECURE_SSL_REDIRECT = True
# Nginx terminates SSL and proxies plain HTTP to Gunicorn.
# Users experience ERR_TOO_MANY_REDIRECTS!
```

**Bug Explanation:**  
When Nginx terminates SSL, it decrypts traffic and forwards plain HTTP to Gunicorn. Django inspects `request.is_secure()`, sees HTTP, and issues an HTTP 301 redirect to HTTPS, creating an infinite redirect loop.

**Fixed Code Solution:**
```python
# Instruct Django to trust Nginx's forwarded protocol header:
SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')
SECURE_SSL_REDIRECT = True
```
