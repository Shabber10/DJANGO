## Section A: Multiple-Choice Questions

#### Q1. Which built-in path converter matches any non-empty string, excluding the path separator `'/'`?
- [ ] **A**. `<path:var>`
- [ ] **B**. `<str:var>`
- [ ] **C**. `<slug:var>`
- [ ] **D**. `<int:var>`

**Answer:** B. `<str:var>`  
*Explanation:* `<str:name>` matches any non-empty string except the forward slash `'/'`. To match strings that include slashes (like file paths), use `<path:name>`.

#### Q2. When reversing a URL pattern with a namespace, what separator syntax is required?
- [ ] **A**. `reverse('app.view_name')`
- [ ] **B**. `reverse('app/view_name')`
- [ ] **C**. `reverse('app:view_name')`
- [ ] **D**. `reverse('app->view_name')`

**Answer:** C. `reverse('app:view_name')`  
*Explanation:* Django uses the colon `:` delimiter to separate URL namespaces from view names (e.g., `reverse('blog:article_detail', kwargs={'pk': 5})`).

#### Q3. What is the HTTP status code returned by default when calling `redirect('home')`?
- [ ] **A**. 301 Moved Permanently
- [ ] **B**. 302 Found (Temporary Redirect)
- [ ] **C**. 200 OK
- [ ] **D**. 307 Temporary Redirect

**Answer:** B. 302 Found (Temporary Redirect)  
*Explanation:* `redirect()` returns a 302 temporary redirect by default. To return a 301 permanent redirect, pass `permanent=True` (`redirect('home', permanent=True)`).

#### Q4. Which attribute on the `HttpRequest` object contains query parameters sent in a GET request (e.g. `?page=2&search=python`)?
- [ ] **A**. `request.PARAMS`
- [ ] **B**. `request.QUERY`
- [ ] **C**. `request.GET`
- [ ] **D**. `request.ARGS`

**Answer:** C. `request.GET`  
*Explanation:* `request.GET` is a dictionary-like `QueryDict` instance containing all HTTP GET query parameters.

#### Q5. What is the correct way to return a JSON response with non-dictionary data (such as a list) using `JsonResponse`?
- [ ] **A**. `JsonResponse([1, 2, 3])`
- [ ] **B**. `JsonResponse([1, 2, 3], safe=False)`
- [ ] **C**. `JsonResponse([1, 2, 3], list_mode=True)`
- [ ] **D**. `JsonResponse.from_list([1, 2, 3])`

**Answer:** B. `JsonResponse([1, 2, 3], safe=False)`  
*Explanation:* By default, `safe=True` ensures the top-level object is a Python `dict` to protect against historical JSON array hijacking vulnerabilities. Passing `safe=False` explicitly allows serializing non-dict top-level data.

## Section B: Conceptual and Scenario-Based Questions

#### Scenario 1: Clean URL Structure and Slug Handling
**Question:** An e-commerce platform wants product URLs formatted as `/products/<category_slug>/<product_id>-<product_slug>/` (e.g., `/products/laptops/104-dell-xps-15/`). Explain how to design the URL pattern and write the view function to retrieve the product efficiently.

**Model Answer:**
1. **URL Pattern:**
```python
# File: products/urls.py
from django.urls import path
from . import views

app_name = 'products'

urlpatterns = [
    path('products/<slug:category_slug>/<int:product_id>-<slug:product_slug>/', views.product_detail, name='detail'),
]
```
2. **View Implementation:**
```python
# File: products/views.py
from django.shortcuts import render, get_object_or_404
from .models import Product

def product_detail(request, category_slug, product_id, product_slug):
    # Query using primary key first (indexed), verifying category and slug match
    product = get_object_or_404(
        Product.objects.select_related('category'),
        id=product_id,
        category__slug=category_slug,
        slug=product_slug,
        is_active=True
    )
    return render(request, 'products/detail.html', {'product': product})
```

from django.urls import register_converter

class FourDigitYearConverter:
    regex = r'[0-9]{4}'

    def to_python(self, value):
        return int(value)

    def to_url(self, value):
        return f"{value:04d}"

## Section D: Debugging Tasks

#### Task 1: Broken Reverse URL Lookup
**Buggy Code Snippet:**
```python
# File: blog/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('article/<int:id>/', views.article_view, name='article-detail'),
]

# File: blog/views.py
from django.shortcuts import redirect

def edit_view(request, id):
    # ... process update ...
    return redirect('article-detail', id)  # Raises NoReverseMatch
```

**Bug Explanation:**  
In Django 5, passing positional arguments directly to `redirect()` or `reverse()` with some URL configurations can trigger `NoReverseMatch`. The robust approach is to pass arguments via keyword arguments (`kwargs={'id': id}`) or as positional arguments matching the exact pattern parameter names.

**Fixed Code Solution:**
```python
# Use kwargs explicitly or reverse with kwargs:
from django.shortcuts import redirect

def edit_view(request, id):
    # ... process update ...
    return redirect('article-detail', id=id)
```
