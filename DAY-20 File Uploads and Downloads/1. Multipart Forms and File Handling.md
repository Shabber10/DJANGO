# 1. Multipart Forms and File Handling

## 1. Introduction

Transmitting binary files—such as photos, PDFs, spreadsheets, and archives—from a user's computer to a web server requires special encoding. Unlike standard text forms that use `application/x-www-form-urlencoded`, file uploads require **Multipart Forms** (`enctype="multipart/form-data"`). Django parses these uploaded files and exposes them via **`request.FILES`**.

---

## 2. Why Do We Need It?

Standard form encoding encodes data as key-value text strings. If you submit a binary image through a standard form without `multipart/form-data`, the browser only transmits the file's filename string, completely omitting the actual file contents!

---

## 3. How It Works

When a multipart form is submitted:
1. The browser streams boundary-delimited binary chunks.
2. Django's **Upload Handlers** intercept the stream:
   - Small files (< 2.5 MB) are held in memory (`InMemoryUploadedFile`) for speed.
   - Large files (> 2.5 MB) are streamed directly to a temporary file on disk (`TemporaryUploadedFile`) to prevent RAM exhaustion.
3. Django populates the dictionary `request.FILES`.

---

## 4. Syntax

### HTML Form (MANDATORY `enctype`!):
```html
<form method="POST" enctype="multipart/form-data">
    {% csrf_token %}
    <input type="file" name="document">
    <button type="submit">Upload</button>
</form>
```

### Django View:
```python
def upload_file_view(request):
    if request.method == "POST":
        # Notice request.FILES passed as the second argument!
        form = UploadForm(request.POST, request.FILES)
        if form.is_valid():
            uploaded_file = request.FILES['document']
            # uploaded_file is an UploadedFile object
            print(uploaded_file.name)
            print(uploaded_file.size)
```

## 5. Practical Examples

### Low-Level File Handling Without Models
```python
# File: core/views.py
from django.shortcuts import render, redirect
from django.core.files.storage import default_storage
from django.core.files.base import ContentFile

def manual_file_upload(request):
    if request.method == "POST" and request.FILES.get('user_file'):
        file_obj = request.FILES['user_file']
        
        # Save file using Django's default storage backend
        saved_path = default_storage.save(f"uploads/{file_obj.name}", ContentFile(file_obj.read()))
        return render(request, 'upload_success.html', {'path': saved_path})
        
    return render(request, 'upload.html')
```

---

## 6. Code Explanation

- `enctype="multipart/form-data"`: Informs the browser to package inputs as binary multipart chunks.
- `request.FILES`: A dictionary-like object containing all uploaded files.
- `form = FormClass(request.POST, request.FILES)`: **CRITICAL!** You MUST pass `request.FILES` when initializing bound forms with file inputs!
- `file_obj.size`: Size of the uploaded file in bytes.
- `file_obj.content_type`: The MIME type reported by the browser (e.g. `image/png`, `application/pdf`).

---

## 7. Expected Output

Querying `file_obj` in view:
```text
Filename: resume_shabber.pdf
Size: 145020 bytes (~141 KB)
MIME Type: application/pdf
```

## 8. Real-World Use Case

Resume submission portals on job boards, profile picture uploaders, and CSV spreadsheet import engines.

---

## 9. Common Mistakes

1. **Forgetting `enctype="multipart/form-data"` on the `<form>` tag:** The single most common beginner error. `request.FILES` will be completely empty!
2. Forgetting to pass `request.FILES` to the form: `form = FormClass(request.POST)` instead of `form = FormClass(request.POST, request.FILES)`.

---

## 10. Best Practices

- Always verify `enctype="multipart/form-data"` is present whenever `<input type="file">` is used.
- Pass both `request.POST` and `request.FILES` to form constructors.
- Keep file size limits enforced in upload validators.

## 12. Interview Questions

**Q1: What are `InMemoryUploadedFile` and `TemporaryUploadedFile` in Django?**  
*Answer:* Django uses two upload handlers by default, governed by `FILE_UPLOAD_MAX_MEMORY_SIZE` (default 2.5 MB). Files smaller than 2.5 MB are loaded into RAM as `InMemoryUploadedFile` for ultra-fast processing. Files larger than 2.5 MB are streamed directly to the operating system's temporary directory as `TemporaryUploadedFile`, preventing massive uploads from exhausting server RAM.

**Q2: What happens if `enctype="multipart/form-data"` is omitted from a form containing a file input?**  
*Answer:* The browser falls back to the default `application/x-www-form-urlencoded` encoding. Under this encoding, the browser sends only the filename as a plain text string in `request.POST` and does not transmit the binary payload, leaving `request.FILES` completely empty.

---

## 13. Summary

- File uploads require `enctype="multipart/form-data"`.
- Uploaded files are accessed via `request.FILES`.
- Forms require `MyForm(request.POST, request.FILES)`.
