# 4. Dynamic File Downloads with FileResponse

## 1. Introduction

Web applications often need to generate and serve files dynamically—such as exporting database records to CSV spreadsheets, generating real-time PDF invoices, or streaming large binary files without buffering them completely in memory. Django provides **`FileResponse`** specifically for streaming file downloads efficiently.

---

## 2. Why Do We Need It?

Using standard `HttpResponse` to serve a 500 MB file loads the entire 500 MB into Python RAM at once, causing severe memory spikes. `FileResponse` streams the file in small chunks directly from disk or memory buffers. Furthermore, it sets appropriate HTTP download headers automatically.

---

## 3. How It Works

- `FileResponse(open_file, as_attachment=True, filename="report.pdf")`:
  - Automatically determines MIME `Content-Type`.
  - Sets `Content-Disposition: attachment; filename="report.pdf"`, prompting the browser to download the file rather than displaying it in the window.
  - Streams file contents in chunks via WSGI/ASGI.

---

## 4. Syntax

```python
from django.http import FileResponse

def download_invoice(request, invoice_id):
    # Open local file in binary read mode
    file_handle = open(f"/path/to/invoices/inv_{invoice_id}.pdf", "rb")
    
    # Return streaming response
    return FileResponse(file_handle, as_attachment=True, filename=f"Invoice_{invoice_id}.pdf")
```

---

## 5. Practical Examples

### Generating Dynamic CSV Spreadsheet Exports on the Fly
```python
# File: reports/views.py
import csv
from django.http import HttpResponse
from store.models import Product

def export_products_csv(request):
    # Create response with CSV content type
    response = HttpResponse(content_type='text/csv')
    response['Content-Disposition'] = 'attachment; filename="product_catalog_2026.csv"'

    writer = csv.writer(response)
    # Write Header Row
    writer.writerow(['ID', 'Name', 'Price', 'Stock Count', 'Status'])

    # Write Data Rows directly to streaming response
    for p in Product.objects.all():
        writer.writerow([p.id, p.name, p.price, p.stock_count, "Active" if p.is_available else "Inactive"])

    return response
```

---

## 6. Code Explanation

- `as_attachment=True`: Prompts the browser to trigger the "Save File" download dialog. If set to `False` (or omitted), browsers attempt to render the file inline (e.g. previewing PDFs in browser tabs).
- `filename="..."`: Specifies the suggested filename shown in the user's download dialog.
- `response['Content-Disposition']`: The standard HTTP header governing download behavior.

---

## 7. Expected Output

When the user clicks the export link:
- Browser initiates an instant file download named `product_catalog_2026.csv`.
- Opening in Excel or Google Sheets displays a formatted spreadsheet.

---

## 8. Real-World Use Case

Exporting transaction ledgers to CSV for accounting, generating dynamic PDF tickets with QR codes, and streaming private document downloads to authorized users.

---

## 9. Common Mistakes

1. **Forgetting to open files in binary mode (`"rb"`):** Opening files in text mode (`"r"`) causes encoding crashes on binary files like PDFs or ZIPs.
2. Forgetting to verify user permissions before streaming private documents, allowing unauthorized users to download confidential records.

---

## 10. Best Practices

- Always verify authentication and permissions before serving private downloads.
- Use `FileResponse` for streaming binary files.
- Always open local files in binary mode (`"rb"`).

## 12. Interview Questions

**Q1: Why is `FileResponse` preferred over `HttpResponse` when serving large files?**  
*Answer:* `HttpResponse` buffers the entire file content in memory before sending it over the network, leading to memory exhaustion when serving large files (e.g., videos, archives, or high-res images). `FileResponse` streams the file in small chunks directly from disk to the network socket, maintaining a flat memory footprint regardless of file size.

**Q2: What is the difference between `as_attachment=True` and `as_attachment=False`?**  
*Answer:* When `as_attachment=True`, Django sets the `Content-Disposition` header to `attachment`, forcing the browser to trigger a "Save As" download prompt. When `as_attachment=False`, Django sets it to `inline`, instructing the browser to render the file directly within the browser window if supported (e.g. displaying a PDF or image in a browser tab).

---

## 13. Summary

- `FileResponse` streams files efficiently without memory spikes.
- `as_attachment=True` forces the browser download prompt.
- Dynamic CSV and PDF reports can be written directly to response streams.
