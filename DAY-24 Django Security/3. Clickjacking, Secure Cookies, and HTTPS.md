# 3. Clickjacking, Secure Cookies, and HTTPS

## 1. Introduction

Transport and frame security protect users from interception and visual deception. **Clickjacking** tricks users into clicking invisible buttons embedded in iframes, while insecure cookies can be intercepted over unencrypted networks. Django provides built-in middleware and configuration flags to enforce HTTPS, secure cookies, and frame sandboxing.

---

## 2. Why Do We Need It?

- **Clickjacking:** An attacker loads your banking site inside a transparent `<iframe>` overlaid on a harmless game, tricking the user into clicking "Transfer Funds".
- **Man-in-the-Middle (MitM):** Attackers on public networks sniff unencrypted cookies or downgrade connections to HTTP.

---

## 3. How It Works

- **`XFrameOptionsMiddleware`:** Adds the `X-Frame-Options: DENY` header, instructing browsers never to render the site inside an `<iframe>`.
- **`SECURE_SSL_REDIRECT = True`:** Automatically redirects all incoming HTTP requests to HTTPS.
- **`SESSION_COOKIE_SECURE = True`:** Ensures session cookies are ONLY sent over encrypted HTTPS connections.
- **`SECURE_HSTS_SECONDS = 31536000`:** Enforces HTTP Strict Transport Security (HSTS), forcing browsers to connect via HTTPS exclusively for 1 year.

---

## 4. Syntax

```python
# File: config/settings.py (Production Security Settings)

# 1. Enforce HTTPS
SECURE_SSL_REDIRECT = True

# 2. Strict Transport Security (HSTS - 1 Year)
SECURE_HSTS_SECONDS = 31536000
SECURE_HSTS_INCLUDE_SUBDOMAINS = True
SECURE_HSTS_PRELOAD = True

# 3. Secure Cookies (HTTPS Only)
SESSION_COOKIE_SECURE = True
CSRF_COOKIE_SECURE = True

# 4. Prevent JavaScript from reading cookies (XSS mitigation)
SESSION_COOKIE_HTTPONLY = True

# 5. Clickjacking Defense (Default: DENY)
X_FRAME_OPTIONS = 'DENY'
```

---

## 5. Practical Examples

### Allowing Iframes for Specific Views Only
If a partner site needs to embed a specific widget (e.g. embedded video or booking form):
```python
# File: widgets/views.py
from django.views.decorators.clickjacking import xframe_options_exempt, xframe_options_sameorigin
from django.shortcuts import render

# Allow this specific view to be embedded anywhere
@xframe_options_exempt
def embeddable_widget(request):
    return render(request, 'widgets/embed.html')

# Allow embedding ONLY from the same domain
@xframe_options_sameorigin
def internal_iframe_view(request):
    return render(request, 'widgets/internal.html')
```

---

## 6. Code Explanation

- `X_FRAME_OPTIONS = 'DENY'`: Completely forbids any site (including your own) from loading your pages inside an `<iframe>`.
- `SESSION_COOKIE_SECURE`: If `True`, browsers will reject transmitting the session cookie if the request is made over plain `http://`.
- `SECURE_SSL_REDIRECT`: Returns HTTP 301 redirect to the `https://` version of the requested URL.

---

## 7. Expected Output

Inspecting production HTTP response headers:
```text
HTTP/1.1 200 OK
Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
Set-Cookie: sessionid=...; Secure; HttpOnly; SameSite=Lax
```

---

## 8. Real-World Use Case

E-commerce payment gateways, banking apps, and sensitive dashboards requiring compliance with financial security standards.

---

## 9. Common Mistakes

1. Enabling `SESSION_COOKIE_SECURE = True` during local development without SSL: The browser refuses to send the cookie over `http://localhost:8000`, causing login sessions to fail immediately!

---

## 10. Best Practices

- Only enable `SECURE_SSL_REDIRECT` and `SESSION_COOKIE_SECURE` in production.
- Keep `X_FRAME_OPTIONS = 'DENY'` unless explicitly building embeddable widgets.
- Enable HSTS with `includeSubDomains`.

## 12. Interview Questions

**Q1: What is Clickjacking and how does Django prevent it?**  
*Answer:* Clickjacking (UI redressing) is an attack where an attacker embeds a target site inside an invisible or transparent `<iframe>` on a malicious page, tricking an authenticated user into clicking buttons on the hidden site. Django prevents this via `XFrameOptionsMiddleware`, which sends the `X-Frame-Options: DENY` (or `SAMEORIGIN`) header, instructing browsers not to allow the page to be displayed in an iframe.

**Q2: What is HSTS (HTTP Strict Transport Security)?**  
*Answer:* HSTS is a security response header (`Strict-Transport-Security`) that instructs browsers that the site must only be accessed using HTTPS, and that any future attempts to connect over HTTP should be automatically transformed into HTTPS by the browser before sending requests, preventing SSL-stripping man-in-the-middle attacks.

---

## 13. Summary

- Clickjacking is blocked by `XFrameOptionsMiddleware`.
- HTTPS is enforced via `SECURE_SSL_REDIRECT` and HSTS.
- Cookies are secured via `SESSION_COOKIE_SECURE` and `HttpOnly`.
